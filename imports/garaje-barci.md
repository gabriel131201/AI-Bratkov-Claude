# Garaje de Barci

## Informatii generale

In orice garaj de barci, jucatorii pot cumpara, depozita sau scoate ambarcatiunile pe care le detin.

Pe server exista doua tipuri de garaje pentru barci:

- Garaj: Barci Jobs
- Garaj: Barci Ilegale

Ambele garaje ofera acces la aceleasi ambarcatiuni.

Jucatorul poate folosi orice garaj de barci ii este mai aproape.

Garajele de barci sunt marcate pe harta cu pictograma unei barci.

## Cum cumperi o barca

Pentru a cumpara o barca:

1. Mergi la orice Garaj de Barci.
2. Deschide meniul garajului.
3. Selecteaza ambarcatiunea dorita.
4. Daca ai suficienti bani, confirma achizitia.
5. Barca este adaugata in garajul tau si poate fi scoasa oricand.

## Garaj: Barci Jobs

Garajul Barci Jobs este destinat in principal jucatorilor care folosesc barci pentru diferite activitati si joburi de pe server.

Din Garaj: Barci Jobs se poate cumpara orice ambarcatiune disponibila in lista de barci.

## Garaj: Barci Ilegale

Garajul Barci Ilegale functioneaza identic cu garajul pentru joburi.

Din Garaj: Barci Ilegale poti:

- cumpara barci;
- scoate barcile detinute;
- depozita barcile.

Lista de vehicule si preturile sunt aceleasi ca la Garaj: Barci Jobs.

## Recomandari

- Barca Clasica este cea mai ieftina varianta si costa maximum 20.000.000$.
- Salupa este o alegere buna pentru inceput.
- Jetski SeaStrike este recomandat pentru viteza si mobilitate.
- Titan Yacht Boat este cea mai scumpa ambarcatiune disponibila.
